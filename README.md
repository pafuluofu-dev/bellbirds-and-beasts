# Bellbirds & Beasts 🔔🦏🍺

Bellbirds & Beasts is an **open-source Fabric mod for Minecraft Java Edition 1.19.2**
that adds **24 custom animal mobs**: the complete *Procnias* bellbird genus (the loudest
birds on Earth), other remarkable living birds and mammals, extinct megafauna, and a
couple of deliberately silly legends. The entity models, textures and code are original
project assets, generated by the tools in this repository; animal audio provenance is
documented in [SOUND_SOURCES.md](SOUND_SOURCES.md).

**BONK.**

## Install

Requires [Fabric Loader](https://fabricmc.net/) + [Fabric API](https://modrinth.com/mod/fabric-api) on **1.19.2**.
Drop the jar into `mods/` on **both server and clients** (it adds entities, so everyone needs it).

## Build

```bash
gradle build
```

Java 17. Sound files (`assets/bellbird/sounds/*.ogg`) are not committed — they are
prepared at package time by the scripts in [`tools/sounds/`](tools/sounds/): the
Three-wattled Bellbird uses two documented real field recordings (trimmed and converted
to Ogg Vorbis with FFmpeg), and **every other creature's voice is generated locally by
FFmpeg from mathematical signal definitions** — no third-party audio involved. Full
per-sound provenance: [SOUND_SOURCES.md](SOUND_SOURCES.md) / [sound_sources.json](sound_sources.json).

Entity textures are generated programmatically by `tools/gen-texture.js`, and
`tools/build-preview.js` renders the interactive CSS-3D model viewer (a static
HTML/JS page — the same file serves as the GitHub Pages site in `docs/`).
No Blockbench involved at any point.
